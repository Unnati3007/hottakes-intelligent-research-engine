RQS Scoring Formulation

Hot Takes computes RQS using a bounded multi-variate penalty function:

RQS = clamp(100 × (0.35·S_pace + 0.30·S_delib + 0.25·H_norm + 0.10·Jitter) - Σ(P_anomalies), 0, 100)
  • • S_pace: Compares dwell time against reading word count threshold.
  • • S_delib: Evaluates trade-off toggle reversals (1-3 flips = high thoughtfulness).
  • • H_norm: Shannon Entropy across choice batteries (-Σ p·log₂ p).
  • • P_anomalies: 15-point penalty per triggered violation flag.
